# FixFlow — Apartment Maintenance Prototype

A working front-end prototype based on the **Fixing the Fixes — Apartment Maintenance UX Case Study**.

## Run
Open `index.html` in a browser. No server or build step is required.

## Prototype interactions
- Report an issue using the form.
- Requests are stored in browser `localStorage` so refreshes keep your demo data.
- Search and filter requests.
- Open any request to see owner, expected resolution and timeline.
- As **Maintenance Staff** or **Society Manager**, change status and assign an owner.
- As **Resident**, confirm a fix to close the loop.
- Activity view acts as the accountability/audit trail.

## Design-thinking link
The prototype directly addresses the case study's core problem: fragmented reporting → unclear priority → unclear ownership → weak status visibility → repeated follow-ups.

The exact solution is a prototype hypothesis, not a validated final product; the source case study explicitly says the problem framing should be validated with real residents, maintenance staff and management.
